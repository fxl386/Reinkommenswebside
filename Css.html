Cascading Style Sheets (CSS)

Die ersten Schritte

CSS ist der nächste Schritt für eine Website. CSS-Dokumente können einfach mit der Endung ".css" erstellt werden. Wichtig ist, dass CSS wie HTML keine Programmiersprache ist, sondern eine Stylesheet-Sprache. Während sich mit HTML das Grundgerüst erstellen lässt, sorgt CSS für das Design (Farben, Layouts, Abstände usw.).
CSS lässt sich auf verschiedene Arten in HTML einbinden, am besten über den Head-Bereich mit einem externen Stylesheet.
Hier sind die wichtigsten Einbindungsarten:

Externes CSS Internes CSS Inline CSS
Wird über den link-Tag im HTML-Head verknüpft. Ideal für sauberen Code und große Projekte. Wird innerhalb eines style-Tags im Head geschrieben. Gut für einzelne Seiten. Wird direkt im HTML-Tag mit dem style-Attribut angewendet. Eher zu vermeiden.

Die wichtigsten Properties (Eigenschaften)

Damit unsere Website auch gut aussieht, brauchen wir CSS-Eigenschaften. Mit color können wir die Textfarbe anpassen.
Mithilfe von background-color können wir dem Hintergrund eine Farbe geben.
font-weight: bold; brauchen wir, um Texte fett zu markieren (ähnlich wie das strong-Tag in HTML).

Mithilfe von text-decoration: none; können wir zum Beispiel die Standard-Unterstreichung von Links entfernen.

Dies wären die wichtigsten Properties für einfaches Text-Styling. Wenn wir die Größe von Überschriften ändern wollen, müssen wir font-size benutzen.
WICHTIG: Die Werte werden oft in Pixeln (px) angegeben, z.B. 24px. Je größer die Zahl, desto größer die Schrift.

Die Selektoren

Wir haben in CSS die Möglichkeit, bestimmte HTML-Elemente gezielt anzusprechen und zu stylen.
Die wichtigsten sind der Klassen- (Class) und der ID-Selektor. Wir schreiben also einen Punkt (.) für Klassen und eine Raute (#) für IDs. Der Unterschied:

  • Bei einer Klasse wird ein Punkt vor dem Namen geschrieben (z.B. .UE4). Klassen können auf einer Seite unendlich oft verwendet werden.
  1. Bei einer ID wird eine Raute geschrieben (z.B. #header). Eine ID darf pro HTML-Seite nur ein einziges Mal vorkommen.

Zusätzlich dazu gibt es noch Element-Selektoren (wie z.B. einfach h2 oder p), womit sich alle Tags einer bestimmten Sorte gleichzeitig stylen lassen.

Der theoretische Teil

Sehen wir uns das CSS Box-Modell an.

Jedes HTML-Element wird in CSS als rechteckige Box betrachtet. Das Box-Modell ist der Standard, der beschreibt, wie Größe und Abstände von Elementen berechnet werden.

Hier die Bestandteile der Box (von innen nach außen):

  • Content: Der eigentliche Inhalt (Text, Bild), dessen Größe mit width und height bestimmt wird.
  • Padding: Der Innenabstand zwischen dem Content und dem Rahmen.
  • Border: Der sichtbare Rahmen um das Element herum.
  • Margin: Der Außenabstand, der das Element von anderen Elementen wegdrückt.

Absolute und relative Einheiten

Absolute Einheiten sind fest und ändern ihre Größe nicht. Die bekannteste ist das Pixel (px). Diese Methode wird meistens für exakte Rahmen oder feste Breiten verwendet.
Relative Einheiten beschreiben die Größe im Verhältnis zu einer anderen Eigenschaft (wie der Standard-Schriftgröße des Browsers oder der Breite des Bildschirms). Beispiele sind Prozent (%), em, rem oder vh/vw. Sie sind flexibler und ermöglichen es, Webseiten "responsive" zu machen (damit sie auf Handys gut aussehen), ohne alle Werte neu berechnen zu müssen.
